## Задание 2. Подготовка данных к обучению (Уровень: Базовый)

* Контекст: Настоящие ML-модели из библиотеки scikit-learn не умеют работать с пропусками (NaN) и требуют строго определенной формы таблиц. Нам нужно подготовить «фичи» (признаки для предсказания) и «таргет» (то, что предсказываем).
* Что сделать:
1. Удалите строки с пропусками в целевых колонках через .dropna().
   2. Выделите признак X (total_reviews) и целевую переменную y (24h_peak_players).
   3. Важно: Переведите X в двумерный массив (матрицу), так как scikit-learn требует этого для признаков. В Pandas это делается так: X = df[['total_reviews']] (двойные квадратные скобки), а y = df['24h_peak_players'].
* Результат: Две переменные (X и y), полностью готовые к подаче в модель.

## Задание 3. Обучение первой модели Линейной Регрессии (Уровень: Средний)

* Контекст: Пора заставить компьютер рассчитать уравнение той самой красной линии из Задания 1.

1. Импортируйте модель: from sklearn.linear_model import LinearRegression.

   3. Обучите модель на ваших данных с помощью метода .fit(X, y).
   4. Выведите на экран главные коэффициенты уравнения прямой: угол наклона (model.coef_) и точку пересечения с осью Y (model.intercept_).
* Результат: Обученная модель, которая теперь умеет предсказывать суточный онлайн для любой гипотетической игры, если мы просто назовем ей количество отзывов.

## Задание 4. Оценка качества модели (Уровень: Продвинутый)

* Контекст: Как понять, хорошая у нас получилась модель или плохая? Для этого в ML измеряют метрики качества.
* Что сделать:
1. Сделайте предсказание для всех ваших игр: y_pred = model.predict(X).
   2. Импортируйте метрику: from sklearn.metrics import r2_score.
   3. Рассчитайте коэффициент детерминации: R2 = r2_score(y, y_pred).
* Результат: Значение R² от 0 до 1. Оно покажет, какую долю изменчивости онлайна успешно объясняет ваша модель. Чем ближе к 1 — тем круче модель справилась с задачей.
