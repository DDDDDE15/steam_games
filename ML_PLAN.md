# План разработки моделей машинного обучения
**Статус: В разработке** (активный этап)

## Контекст
Цель этапа — построить регрессионные модели, прогнозирующие успех игры в Steam на основе её характеристик. На основе результатов EDA были выявлены ключевые зависимости, которые лягут в основу ML-моделей:<br>

- total_reviews и estimated_owners полностью дублируют друг друга → в моделировании используем только один из признаков (во избежание мультиколлинеарности);
- total_reviews сильно коррелирует с 24h_peak_players (~0.73) — хороший базовый признак для прогнозирования онлайна;
- review_score_pct слабо коррелирует с total_reviews (0.10) → задача прогнозирования оценок сложнее и требует учёта множества факторов.

Целевые переменные<br>

|Переменная	|Задача	|Комментарий|
|---|---|---|
|24h_peak_players|	Прогноз пикового онлайна|	Стартовая задача — сильная линейная зависимость с total_reviews|
|review_score_pct|	Прогноз доли положительных отзывов|	Более сложная задача — требуется множество признаков|
|estimated_owners|	Прогноз числа владельцев|	Практически дублирует задачу с total_reviews| <br>

**Отправная точка**: прогнозирование 24h_peak_players на основе total_reviews.

## Структура работы
### **Блок 1. Линейная регрессия**<br>
Знакомство с базовыми концепциями ML на простейшем примере: одна фича, одна целевая переменная, линейный алгоритм.<br>

1.1. Визуальная регрессия (sns.regplot).<br>
1.2. Подготовка данных: выделение X и y, работа с формой данных.<br>
1.3. Обучение LinearRegression, интерпретация коэффициентов.<br>
1.4. Разделение на train/validation, метрики качества (MAE, R²).<br>
1.5. Кросс-валидация для устойчивой оценки.<br>

### **Блок 2. Дерево решений**<br>
Переход к нелинейным алгоритмам. Добавление числовых признаков. Знакомство с переобучением и гиперпараметрами.<br>

2.1. Первое дерево решений, сравнение с линейной регрессией.<br>
2.2. Борьба с переобучением через max_depth и max_leaf_nodes.<br>
2.3. Добавление числовых признаков (price_usd, discount_pct, release_year), анализ feature_importances_.<br>

### **Блок 3. Случайный лес, пайплайны и One-Hot Encoding тегов**
Ключевой блок: работа с категориальными признаками, включая теги через OHE, построение воспроизводимых пайплайнов, ансамблевые методы.<br>

3.1. Знакомство с RandomForestRegressor, сравнение с одиночным деревом.<br>
3.2. Подбор n_estimators через кросс-валидацию.<br>
3.3. Категориальный признак primary_genre: OrdinalEncoder vs OneHotEncoder.<br>
3.4. One-Hot Encoding тегов игры — «мешок слов» через str.get_dummies(sep=';'), фильтрация редких тегов.<br>
3.5. Построение полного пайплайна (Pipeline + ColumnTransformer).<br>
3.6. Обработка пропущенных значений: удаление, SimpleImputer, расширенное заполнение.<br>
3.7. XGBoost: сравнение с Random Forest, подбор гиперпараметров.<br>
3.8. Предотвращение утечки данных (data leakage): анализ производных признаков.<br>
3.9. Финальная модель и интерпретация важности признаков.<br>
