# Анализ игр Steam (Pet-проект)

**Статус: Анализ завершен, переход к ML** (текущий фокус — разработка моделей машинного обучения)

Данный проект представляет собой исследование факторов, влияющих на успех видеоигр в Steam, с использованием методов статистического анализа и визуализации данных. Первичный анализ данных (EDA) и проверка гипотез завершены, что создало прочную основу для следующего этапа — построения прогнозных моделей.

## Цель проекта
Выявить скрытые зависимости и ключевые паттерны, которые делают игру популярной или высокооцененной. Исследование включает проверку гипотез о влиянии цены, жанра, скидок и других факторов.<br>
На данный момент проект переходит к этапу машинного обучения для прогнозирования успеха игр.

## Ключевые результаты анализа (EDA)
Первичный анализ данных выявил следующие закономерности:
1. Влияние цены: Платные игры в среднем получают более высокие оценки, чем бесплатные. Однако прямой корреляции между ценой в долларах и итоговым рейтингом нет.

2. Влияние скидок: Наличие скидки не является значимым фактором для набора большого количества отзывов. Самые популярные проекты (супер-хиты) часто имеют нулевую скидку.

3. Жанровые предпочтения: Наибольшее медианное число владельцев и пиковый онлайн демонстрируют жанры Action, RPG и Massively Multiplayer. Это указывает на их ключевую роль в привлечении широкой аудитории.

4. Динамика по годам: Наблюдается общая тенденция к снижению средней оценки игр с годами. При этом оценки платных игр более стабильны, в то время как у бесплатных проектов бывают как "провальные", так и успешные годы.

5. Корреляция метрик: Метрики total_reviews и estimated_owners полностью дублируют друг друга, а total_reviews сильно коррелирует с 24h_peak_players. Это важно учитывать для избежания мультиколлинеарности при построении моделей.

## Данные

**Источник:** [Top 1000 Steam Games (2024–2026)](https://www.kaggle.com/datasets/waddahali/top-1000-steam-games-20242026)

Данные были взяты с Kaggle и содержат информацию о 1000 самых продаваемых и популярных играх в Steam, собранный в марте 2026 года.
CSV-файл содержит 12 структурированных столбцов.

**Важно:** 
- Сам файл с данными не включен в репозиторий из-за большого размера.
- Чтобы запустить проект, скачайте датасет по ссылке выше и поместите файл `steam_games_2026.csv` в папку `data/`.

**Описание данных:**

|Column|  Type  |Description|
|:---|:------:|---|
|AppID|  int   |Unique Steam application ID|
|Name|  str   |Full game title|
|Release_Date|  date  |Official release date (YYYY-MM-DD)|
|Primary_Genre|  str   |First genre listed (Action, Indie, RPG, etc.)|
|All_Tags|  str   |Up to 10 semicolon-separated community tags|
|Price_USD| float  |Current price in USD (0.00 = Free to Play)|
|Discount_Pct|  int   |Active discount % at time of scrape (0–95)|
|Review_Score_Pct|  int   |% of positive reviews (0–100)|
|Total_Reviews|  int   |Total user reviews|
|Steam_Deck_Status|  str   |Deck compatibility (Verified / Playable / Unsupported / Unknown)|
|Estimated_Owners|  int   |Estimated owners (Total Reviews × 30)|
|24h_Peak_Players|  int   |Peak concurrent players in last 24h (SteamSpy)|
